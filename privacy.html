适用范围 · Scope

本政策适用于“xiafan uploader”，这是下饭英语频道自用的上传工具，只用于把本频道制作的视频上传到本频道自己的 YouTube 账号。它不向公众开放，不提供给其他用户使用。

This policy covers “xiafan uploader”, a private tool used only by the Xiafan English channel to upload its own videos to its own YouTube channel. It is not offered to the public or to other users.

我们访问的数据 · Data we access

经频道所有者授权，工具通过 YouTube Data API 上传视频、设置封面、上传字幕，并读取本频道的名称以确认上传到正确的频道。它不读取、不收集任何其他用户、观众或第三方的个人信息。

With the channel owner’s authorisation, the tool uses the YouTube Data API to upload videos, set thumbnails, upload captions, and read the channel’s own name to confirm it is uploading to the right channel. It does not read or collect personal information about any other user, viewer or third party.

存储与共享 · Storage and sharing

授权凭据只保存在频道所有者自己的电脑上，不上传到任何服务器，不出售、不出租、不与任何第三方共享。频道所有者可以随时在 Google 账号的“第三方应用访问权限”页面撤销授权。

The authorisation token is stored only on the channel owner’s own computer. It is never sent to any other server, and no data is sold, rented or shared with anyone. The owner can revoke access at any time at myaccount.google.com/permissions.

Google API 服务 · Google API Services

本工具对 Google API 所获信息的使用遵守 Google API Services User Data Policy，包括其中的“有限使用”要求，并遵守 YouTube 服务条款和 Google 隐私政策。

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements, the YouTube Terms of Service and the Google Privacy Policy.

网站 · This website

本网站是静态页面，不使用 Cookie，不做访问统计。网站由 GitHub Pages 托管，GitHub 可能按其自身政策记录访问日志。

This website is static, uses no cookies and no analytics. It is hosted on GitHub Pages, which may keep server logs under its own policy.
